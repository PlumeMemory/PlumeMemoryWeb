羽忆 Memory Server API

统一云记忆基础设施 REST API —— 为多 Agent 提供统一长期记忆服务。

文档说明：

  • 记忆读写接口默认支持 Authorization: Bearer {token} 或管理员 Session Cookie
  • /v1/admin/** 和 /v1/auth/me、/v1/auth/logout 仅允许管理员 Session 访问
  • /v1/auth/login 用用户名密码登录，成功后服务端会写入 JSESSIONID HttpOnly Cookie
  • 所有接口统一返回 {code, message, data, httpStatus, timestamp} 结构
  • code 是稳定业务码，成功固定为 SUCCESS / CREATED，失败为 MEM-*
  • 列表、搜索、最近记忆接口返回摘要模型；详情接口返回完整对象
  • scope.userId 由服务端按当前登录用户校验，不能借请求体伪造其他用户

Authentication​

  • HTTP: Bearer Auth
  • API Key: AdminSession

API Token 认证，格式：Bearer {token}。适用于 CLI / MCP / 自动化调用。

Security Scheme Type:

http

HTTP Authorization Scheme:

bearer

Bearer format:

Token

管理员浏览器登录态。通过 /v1/auth/login 登录成功后，由服务端写入 HttpOnly Session Cookie。

Security Scheme Type:

apiKey

Cookie parameter name:

JSESSIONID
